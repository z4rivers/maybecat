
# Found Language: How Critics Describe Comedians

Collected 2026-02-17. These are the quirky, evocative, physical, unusual ways journalists and critics DESCRIBE comedians and their styles. This language, relocated into a cat's mouth, becomes MaybeCat answers.

## Maria Bamford

1. **"like a lobster whose shell has been removed"**
   - Conan O'Brien describing Bamford's comedy
   - Source: https://www.thedailybeast.com/obsessed/how-maria-bamford-became-every-comedians-favorite-comedian/
   - Cat answer: "You're a lobster whose shell has been removed. Text them."

   - Daily Beast profile
   - Source: https://www.thedailybeast.com/obsessed/how-maria-bamford-became-every-comedians-favorite-comedian/

   - Source: https://en.wikipedia.org/wiki/Maria_Bamford

   - Source: Web search aggregate
