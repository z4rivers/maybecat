## Common Workflows

**Adding cat responses:**
1. Check `CAT-VOICE-GUIDE.md` for voice rules
2. Use `ADD-RESPONSES-PROMPT.md` for generation strategy
3. Generate batch using comedian filter or concept mashup
4. Review in HTML file (KEEP/CUT/EDIT)
5. Export JSON and send to agent for insertion into `oracleResponses.ts`

**Finding voice inspiration:**
1. `famous-cats-reference.md` for cat archetypes
2. `research/` files for specific voice filters (musicians, comedians, etc.)
3. `response-pool-audit-2026-02-13.md` for gaps and opportunities

**Understanding SEO strategy:**
1. `seo-research/STRATEGY.md` for positioning
2. Competitor research files 01-09 for landscape
3. `10-content-scaling-strategy.md` for execution plan

**Design system work:**
1. Check `STATE.md` for current phase
2. Read phase `RESEARCH.md` or `CONTEXT.md`
3. Execute phase `PLAN.md` files in order
4. Update `STATE.md` when complete
